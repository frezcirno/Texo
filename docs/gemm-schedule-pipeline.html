加载：默认 CTA 有 128 个线程；线程按 16 字节（8 个 half）一组，协作搬运 A/B tile，下一阶段的拷贝分散在 MMA 子步之间。
计算：一个 warp 的 32 个 lane 协作加载片段并执行 Tensor Core MMA；每个 warp 负责一个 WM×WN 输出子块，不是一个 lane 对应一个 C 元素。Tensor Core 是 SM 内的执行单元，不是每个 warp 独占一颗。
